# PDF Toolpack™ v2.1

A lightweight 6-in-1 desktop utility for working with PDF and document files quickly, privately, and completely offline.

PDF Toolpack™ is built for people who regularly work with documents and would rather process their files directly on their own computer instead of uploading them to online conversion websites.

## What It Does

PDF Toolpack brings together six everyday document utilities in one portable desktop application:

1. Merge PDFs
2. PDF to Word
3. Word to PDF
4. PDF to Excel
5. Images to PDF
6. Heavy PDF Compression

![PDF Toolpack v2.1 Interface](images/pdf-toolpack-preview.png)

The application is designed to run locally on your Windows PC with no installation wizard required.

## Why PDF Toolpack?

A lot of PDF conversion tools work through websites. That means uploading documents to external servers, waiting for files to be processed, and then downloading the results again.

PDF Toolpack takes a different approach.

Your files are processed directly on your computer.

- No document uploads to online conversion websites
- No internet connection required for normal offline workflows
- No upload queues or browser processing delays
- No monthly subscription required for the standalone tool
- Portable and lightweight
- Quick access from your desktop

This makes it especially useful for handling documents when privacy, speed, and offline access matter.

## Getting Started

Getting started takes only a few steps.

### 1. Download PDF Toolpack

Download the PDF Toolpack archive from the official product page:

[PDF Toolpack™ v2.1](https://cursorlordsystems.com/pdf-toolpack)

### 2. Extract the Archive

Unzip or extract the downloaded folder to any location on your computer.

There is no installation process required.

### 3. Create a Desktop Shortcut

Open the extracted folder and locate:

`PDFToolpack.exe`

Right-click the application and select:

`Send to → Desktop (create shortcut)`

You can then launch PDF Toolpack directly from your desktop whenever you need it.

### 4. Start Working

Open the application and choose the utility you need.

You can merge PDF files, convert supported documents, create PDFs from images, or compress large PDF files without uploading your documents to an online service.

## System Requirement

Some document and Office conversion features require Microsoft Word to be installed on the PC.

This allows PDF Toolpack to use native document and Office conversion capabilities where required.
